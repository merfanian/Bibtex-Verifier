How it works

1

Upload or paste

Drop your .bib file or paste directly from Overleaf. Everything is parsed in your browser — nothing is uploaded to any server.

2

Verify

Each entry is looked up by title against Semantic Scholar and CrossRef, with OpenAlex as a fallback. Authors, year, venue, DOI, and other fields are compared to the published record. Entries that don't match any real publication are flagged — perfect for catching AI-hallucinated citations.

3

Review & edit

Results are color-coded: Verified means everything matches, Auto-Updated shows a diff you can accept or edit inline, and Needs Review flags possible errors. A live preview shows the corrected BibTeX in real time.

4

Download

Download or copy the corrected .bib file with your changes applied. Ready for LaTeX, Overleaf, or any reference manager.

Features

Hallucination detection

Flags entries whose titles don't match any known publication — catches fabricated references from AI-generated bibliographies.

Multi-source verification

Uses Semantic Scholar and CrossRef, with OpenAlex fallback, to maximize coverage and metadata quality.

Field-by-field diff

See exactly which fields differ — authors, year, venue, DOI, pages — with inline editing and a live BibTeX preview.

Privacy-first

Your file never leaves the browser. Only paper titles, DOIs and arXiv IDs are sent to public academic APIs for lookup. No server, no tracking; your progress is saved only in this browser.

DOI & metadata enrichment

Fills in missing DOIs, publisher info, volume, pages, and other metadata from the online record automatically.

Smart matching

Fuzzy title matching, LaTeX-aware text processing, and last-name-based author comparison handle real-world formatting differences.

Questions

Something else? Open an issue on GitHub.

Can it detect AI-hallucinated references?

Yes. When a BibTeX entry's title doesn't match any real publication in Semantic Scholar, CrossRef, or the OpenAlex fallback, it's flagged as "Not Found" or "Needs Review." This is how fabricated citations from ChatGPT, Copilot, or other AI tools get caught — the paper simply doesn't exist in any checked academic database.

Is my data safe?

Yes. Your .bib file is parsed entirely in your browser using JavaScript. The only network requests made are lookups by title, DOI or arXiv ID to the public Semantic Scholar, CrossRef, and OpenAlex APIs, plus one request to GitHub for the star count in the header. No file content is sent to any server.

Why are some entries "Not Found"?

Not every paper is indexed in Semantic Scholar, CrossRef, or OpenAlex. ArXiv preprints, workshop papers, theses, and very recent publications may not be found. The tool flags these so you can verify them manually — or remove them if they're fabricated.

Why does verification take a while?

To respect the free APIs' rate limits, requests are sent at a controlled pace with adaptive throttling. For a file with 50 entries, expect roughly 2–3 minutes. You can review results and change settings while it's still processing.

Does it work with Overleaf?

Yes! You can copy your entire .bib file from Overleaf and paste it directly into the "Paste BibTeX" tab. After reviewing, download the corrected file and upload it back to Overleaf.

Is this open source?

Yes! The full source code is on GitHub under the MIT license. Contributions are welcome.

Semantic Scholar API key optional

Without a key, Semantic Scholar turns away about two in three requests, and each entry it must be asked about on its own takes several seconds. With your own free key those lookups go through at once. Request a key (Semantic Scholar sends it by email).

The key is stored only in this browser and sent only to Semantic Scholar. It is used from the next lookup on.

Download options

Formatting fixes, duplicates, author limits and the peer-reviewed preference are set from the gear in the bar at the bottom of the page, which appears once a run starts.

BibTeX Verifier checks every entry of a .bib file against public databases and shows what doesn’t match: wrong authors, venues and years, missing DOIs, duplicates, retracted papers, and citations that don’t exist at all.

Privacy

Everything runs in your browser; there is no server. Only paper titles, DOIs and arXiv IDs are sent to the databases. Your progress and, if you add one, your API key are stored only in this browser.
